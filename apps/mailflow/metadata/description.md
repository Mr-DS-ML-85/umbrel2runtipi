# MailFlow

Unified self-hosted webmail client

MailFlow is a self-hosted unified webmail client. Connect multiple IMAP/SMTP accounts such as Gmail, iCloud, Outlook, or custom mail servers and read them in one web interface.

It includes a unified inbox, search, compose/reply/forward, folder navigation, multiple themes, user management, SSO/OIDC support, and Microsoft 365 OAuth2 support.

## Release notes

MailFlow 2.9.0 adds a message-pane context menu with copy, select, find, print, and common message actions.

A new appearance setting can hide message preview snippets for a denser message list, and the preference syncs across devices.

This release fixes backend crashes caused by IMAP socket timeouts and allows System Email to use private or local SMTP relays when that policy is enabled.

It also includes security-related dependency updates for nanoid, DOMPurify, and PostCSS.

No manual upgrade steps are required.
