# MeshChatX

The future of off-grid communication. Secure, decentralized, and unstoppable

A Reticulum Network-based communication application with the goal of providing everything you need for Reticulum, LXMF, and LXST in one beautiful and feature-rich application. 

This project is separate from the original Reticulum MeshChat project, and is not affiliated with the original project.

Features:
  - Full LXST support
  - Custom voicemail
  - Phonebook
  - Contact sharing
  - Ringtone support
  - Multi-identity handling
  - Modern UI/UX
  - Offline documentation
  - Expanded tools
  - Page archiving
  - Integrated maps
  - Improved application security

## Release notes

This update adds a plugin system, RNS File Sync with an in-app file manager, map overlays, message import/export, and message maintenance tools.

It improves Docker/headless audio support, startup speed, conversation loading, Reticulum and LXMF interface controls, Relay Chat rooms, notifications, and system/resource visibility.

It also fixes Web Sync recovery, identity switching, Reticulum config repair, interface settings refreshes, unread badges, link routing, startup logging, and frozen desktop builds.

Full release notes can be found at https://github.com/Quad4-Software/MeshChatX/releases/tag/v4.8.1
