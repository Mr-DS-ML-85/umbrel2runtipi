# Coolify

Self-hosted Heroku / Netlify alternative

Coolify is an open-source, self-hostable Platform as a Service (PaaS) alternative to Vercel, Heroku and Railway. Deploy applications, databases and Docker Compose stacks from git, Docker images or templates with automatic SSL, all through a web UI.

It manages the host Docker engine through the socket. For realtime features the optional `soketi` service is omitted in this packaging; the dashboard and deployments work without it.
