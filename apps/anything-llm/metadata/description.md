# AnythingLLM

AI workspace for chat, documents, and agents

AnythingLLM is a self-hosted AI workspace for chatting with LLMs, building knowledge bases from your documents, and creating custom AI agents.

It supports OpenAI, Anthropic, Gemini, Ollama, LocalAI, OpenRouter, and many other model providers, with local storage for conversations, workspaces, documents, vector indexes, and provider settings.

## Release notes

This release adds AnythingLLM's new Magic Features for desktop clients and improves chat, agent, embedding, and workspace behavior.

- Introduced Magic Echo, Magic Beacon, and Magic Tab for OS-wide AI dictation, text actions, and autocomplete in supported desktop clients - Unlocked the chat history cap - Enabled intelligent tool selection by default - Fixed API embedding updates that could fail on Windows-style paths - Added query and passage prefix options for Generic OpenAI embedders
