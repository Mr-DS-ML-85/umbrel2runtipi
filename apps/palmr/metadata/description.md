# Palmr

Open-Source File Transfer

⚠️ Removal Notice: The Palmr project is no longer maintained and is not getting any more updates. For more information, see this update: https://github.com/kyantech/Palmr/issues/418

🌴 Palmr. is an open-source file-sharing platform focused on privacy and security. 

It enables users to upload, manage, and share files with features like password protection, custom links, and  access control without tracking or limitations. 

Designed for seamless and secure sharing, Palmr. is completely free.

## Release notes

This update includes important bug fixes and security improvements.

Key changes include:
  - 🚨 Updated Next.js to address a critical remote code execution vulnerability (CVE-2025-51605)
  - Fixed file manager refresh issues after creating and renaming folders
  - Resolved large file upload failures (10GB+) on S3-compatible storage
  - Fixed large file downloads failing in Firefox
  - Resolved 401 errors on Reverse Share uploads for files 100MB or larger
  - Fixed audio and video preview issues when behind a reverse proxy
  - Fixed 2FA button overflow on smartphones


Full release notes can be found at https://github.com/kyantech/Palmr/releases
